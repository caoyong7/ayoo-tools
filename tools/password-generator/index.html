Password basics

Long, unique passwords are easier to manage safely than short passwords reused across sites. A password manager can create and remember a different password for each account, which is safer than trying to memorize variations of one password.

Recommended use

  • Use at least 14 to 16 characters when the website allows it.
  • Use a different password for every important account.
  • Store generated passwords in a trusted password manager.
  • Turn on two-factor authentication for email, banking, cloud, and admin accounts.

Example password habits

Weak habit: reusing one familiar password with a different number at the end.

Stronger habit: generating a unique random password for each account and saving it in a password manager.

FAQ

Does this tool send the password to a server?

The password is generated in your browser using the Web Crypto API. Do not paste generated passwords into chat, notes, or screenshots.

What length should I choose?

Sixteen characters is a practical default for many accounts. Use longer passwords for sensitive accounts when the site supports them.

Why did the default length change to 16?

Eight characters is often too short for modern account security. Sixteen is a better everyday default while still being accepted by most websites.
